# 📊 Romanian Demographics & Kindergarten Context Analysis

## 📌 Overview
This Business Intelligence project utilizes **Tableau** to analyze demographic data in Romania, specifically focusing on live births and the early childhood population (0-9 years old) across different counties between 2021 and 2022. The insights derived from this analysis are intended to provide a contextual understanding for planning and evaluating the need for educational infrastructure, such as kindergartens.

## 🚀 Key Features
*   **Interactive Dashboards:** Visual representations of demographic trends, allowing for filtering and exploration by county and year.
*   **Data Integration:** Consolidation of multiple datasets regarding live births and age-specific population distribution.
*   **Insight Generation:** Clear visualization of regions with the highest density of early childhood populations.
*   **Data Preparation Flow:** Includes the data cleaning and preparation steps managed through Tableau Prep Builder (`.tfl`).

## 📂 Project Structure
*   **`Data/`**: Contains the raw and processed dataset files (`.csv`) used for the analysis, detailing live births and population demographics.
*   **`Tableau/`**: Includes the Tableau Packaged Workbook (`.twbx`), the standard workbook (`.twb`), and the Tableau Prep flow file (`.tfl`) used for data modeling.
*   **`Proiect_BI_Gradinite.pdf`**: A static export of the final dashboard for quick viewing without requiring Tableau software.

## 🛠️ Technologies & Tools
*   **Data Visualization & Analysis:** Tableau Desktop
*   **Data Preparation:** Tableau Prep Builder
*   **Data Format:** CSV

## ⚙️ How to View
1.  **Static View:** Open the `Proiect_BI_Gradinite.pdf` file directly in your browser or PDF viewer.
2.  **Interactive View:** To explore the dashboards interactively, download the `Proiect_BI_Gradinite.twbx` file from the `Tableau/` folder and open it using **Tableau Desktop** or the free **Tableau Reader**.
